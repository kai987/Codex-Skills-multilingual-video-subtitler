## Evidence and source coordinates

Every artifact carries original source media SHA-256, duration, selected audio stream, original sample rate/timebase, and `SOURCE_GLOBAL_SECONDS`. A 16 kHz extraction rate is not the original media sample rate. Verify native request/VAD/token hashes, integer sample conversions, and exact request cross-links. Unknown or contradictory coordinate provenance is quarantined, not coerced to source time. Shared request/candidate roots count as correlated evidence.

A review item is a container. Its old core or parent gap is not the interval to be heard. Emit independent full-current-cue targets, atomic missing-speech islands, verified candidate-source targets, and orphan targets. Keep disjoint targets separate. Never expand or change a target because a Gold example was missed. Full current-cue intervals are required for hallucination review.

Build speech islands from verified machine acoustic evidence across the whole source, independently of the existing queue. Parent gaps are search envelopes only. Sweep the global evidence against exact canonical cue/target coverage to retain orphan speech. Observed speech, localized lexical content, strong cross-model agreement, empty output, disagreement, contradiction, and unresolved localization remain different states. None gives canonical coverage credit or permission to generate a cue automatically.
